# SEO Plan

## Development phase

The GitHub Pages development site is not intended to rank in search engines. It uses `noindex, nofollow` while the business name, content, contact details, and production domain are still being finalized.

Do not submit the GitHub Pages URL to Google Search Console.

## Production phase

After the final domain is connected, add or confirm:

- index/follow robots metadata
- production canonical URLs
- page-specific titles and meta descriptions
- Open Graph metadata
- sitemap.xml
- robots.txt
- Organization or ProfessionalService structured data as appropriate
- Google Search Console verification
- analytics if desired

Potential local search themes should be used naturally, not repeated mechanically. Examples include:

- Minneapolis web design
- web designer Minneapolis
- small business web design Minneapolis
- custom websites Minneapolis
- website design for small business Minnesota

The site should primarily earn relevance through clear service copy, real project case studies, local context, and useful content rather than keyword stuffing.


## Google Business Profile

After the production domain is live, create and verify a Google Business Profile for Mill City Web Studio.

Recommended setup checklist:

- Use the final business name consistently with the website.
- Add the production website URL.
- Add the Minneapolis service area and appropriate business category.
- Add a concise business description focused on small-business website design and development.
- Add the Mill City logo and a few strong brand/project images.
- Add core services such as new website design + build, website refreshes, and website updates.
- Keep hours/contact information accurate.
- Link to the verified production site rather than the GitHub Pages development URL.
- After verification, connect the production domain to Google Search Console and submit the sitemap.

The website and Business Profile should use the same core business details so Google sees a consistent local business identity.
