# SEO Plan

## Development phase

The GitHub Pages development site is not intended to rank in search engines. It uses `noindex, nofollow` while the business name, content, contact details, and production domain are still being finalized.

Do not submit the GitHub Pages URL to Google Search Console.

## Production phase

After the final domain is connected, add or confirm:

- index/follow robots metadata
- production canonical URLs
- page-specific titles and meta descriptions
- Open Graph metadata
- sitemap.xml
- robots.txt
- Organization or ProfessionalService structured data as appropriate
- Google Search Console verification
- analytics if desired

Potential local search themes should be used naturally, not repeated mechanically. Examples include:

- Minneapolis web design
- web designer Minneapolis
- small business web design Minneapolis
- custom websites Minneapolis
- website design for small business Minnesota

The site should primarily earn relevance through clear service copy, real project case studies, local context, and useful content rather than keyword stuffing.
